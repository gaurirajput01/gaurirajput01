### 🏢 Internship Deep-Dive: Niagara BMS Bot

*Private repository — code isn't public, but here's what I built and how.*

**Abistika Tech · AI Engineer Intern · April 2026**

A serverless conversational AI assistant that lets facility teams query building-management systems in plain English instead of writing BQL manually.

- **Architecture:** Fully serverless on AWS — API Gateway → Lambda → Bedrock (Mistral Large 3), with a multi-layer intent-routing pipeline to classify and dispatch natural-language queries.
- **Retrieval:** Built a RAG pipeline using **Titan V2 embeddings** indexed over S3, retrieving relevant BMS schema/context before generation.
- **Query generation:** Used few-shot prompting to generate validated **BQL** queries, with write-operation safety checks to prevent unsafe commands from executing.
- **Extension — `/data-chat`:** Added an additive Lambda pipeline for real-time analysis of live data tables, using **Supabase** to persist multi-turn conversational memory across sessions.
